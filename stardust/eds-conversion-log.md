## Page grid

`main` is a CSS grid on the live 1180 container: `content-start / primary-end` is the live 9-3
primary column (74.58% / 66.10% ≤1080), `aside-start / aside-end` the secondary column, `full-*`
the viewport. Sections sit in the primary column by default; `full`/`dropcap` sections, the hero,
cinemagraph, columns and the 6-6 / 3-3-3-3 card grids span wider. The aside section is placed
beside the run of sections before it (`--aside-row` / `--aside-span`, set by the aside block),
and stacks after them below 800px.

Section-style vocabulary (one value per section, carries the live layout-row rhythm):
`continued`, `spaced`, `full`, `dropcap`, `disclaimer`, `gap`, `gap-wide` — see the importer header.

## Known gaps / residuals

- The query index only fills on **publish** (aem.live); until then archive/latest/search use the
  authored rows only. The index config (query.yaml) is in place.
- Edit-mode drift (Experience Workspace only, no published impact): cards heading row +30px, the
  news contact sidebar −231px (its spacing rules use sibling selectors the editor wrappers break).
- block-roundtrip harness cannot run blocks that import `/scripts/site.js` or `aem.js` (cards,
  accordion, terms-gate): those were verified on the dev server instead (pixel + drive).
- Plugin finding: `localize-links.mjs` does not map `*.plain.html` files to page paths (it kept
  every internal link absolute); link localization is done by the importer (`MIGRATED_PATHS`).
- The html-folder preview serves pages without a doctype (quirks mode); the local probes inject it.
- Mobile nav tray and the leaving-HSBC dialogs are not part of a gated archetype (interim styling).
- Not migrated yet: 290 pages. Their links stay absolute to the live site until their wave ships
  (add the path to `MIGRATED_PATHS` in `tools/importer/utils.js` and re-run the import).
